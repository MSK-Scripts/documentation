# Willkommen bei den Anleitungen von MSK Scripts

Hier findest du Schritt-für-Schritt-Anleitungen, Tipps und bewährte Vorgehensweisen zu den
Ressourcen von MSK Scripts, von der ersten Einrichtung bis zur tiefergehenden Anpassung.

---

## Was dich erwartet

Anleitungen gehen weiter als die reine API-Referenz. Statt einzelner Events und Exports
zeigen sie dir, wie du übliche Aufgaben von Anfang bis Ende erledigst:

- **Einrichtung und Konfiguration**: Ressourcen zum Laufen bringen und auf deinen Server zuschneiden
- **Integration**: MSK-Scripts-Ressourcen mit anderen Scripts verbinden
- **Anpassung**: Icons, Sounds, Hintergründe und mehr
