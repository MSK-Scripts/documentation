# Keymaster

**Asset Escrow:** https://forum.cfx.re/t/introducing-asset-escrow-for-your-resources/

## Error parsing script / Failed to load script

Deine Server-Artifacts sind vermutlich veraltet. Bring deinen Server auf Version 5181 oder neuer.

## You lack the required entitlement to use \<resource\>

Starte den Server neu und prüfe, ob dein Server-Lizenzschlüssel stimmt. Hast du die Ressource auf dem falschen Konto gekauft, kannst du sie unter https://keymaster.fivem.net/ auf ein anderes Konto übertragen.

## Failed to verify protected resource

Beim Übertragen sind womöglich Dateien beschädigt worden. Achte darauf, dass versteckte Dateien mitkopiert werden, denn die Datei `.fxap` gehört zwingend zu einer geschützten Ressource. Manche FTP-Programme lassen solche Dateien aus.

## Could not find dependency `msk_core` for resource \<resource\>

Für die neuesten Fassungen unserer Produkte wird `msk_core` gebraucht. Hier gibt es das Script: https://github.com/MSK-Scripts/msk_core
