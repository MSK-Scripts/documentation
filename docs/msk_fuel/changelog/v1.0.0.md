# v1.0.0

First release. Fuel system built on the FiveM
[fuel consumption](https://docs.fivem.net/docs/scripting-manual/using-new-game-features/fuel-consumption/)
game feature, with the whole fuel state on StateBags.

- Four fuel types (gas, diesel, kerosin, electric) mapped per vehicle model
- Nozzle with a physical rope, attached to the vehicle's fuel cap
- Petrolcan: buy, refill and fuel vehicles anywhere
- Wrong fuel causes progressive engine failure
- Fuel is only consumed while the engine runs; a damaged tank leaks
- Map pumps, custom stations, and vehicles or trailers as mobile stations
- German and English translations
